## 🎮 About 4 FIRE UNITED

**4 FIRE UNITED (4FU)** is a modern esports platform designed to provide a complete digital experience for an esports team.

The platform includes a public esports website, dynamic player profiles, player dashboard, tournament registration, gallery, gameplay clips, announcements, live chat, notifications, Game Center and a complete admin CMS.

The platform uses Firebase services for dynamic data and authentication, along with Cloudinary for media management.
